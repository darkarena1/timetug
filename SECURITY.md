# Security policy

## Reporting a vulnerability
Please report vulnerabilities privately using GitHub's "Report a vulnerability" button on the
[Security tab](https://github.com/darkarena1/timetug/security/advisories/new) (private advisories).
Do not open a public issue for security problems. You can expect an acknowledgement within a few days.

## In scope
- Handling of calendar data (events, attendees, locations, notes), including anything written to logs or disk
- Opening links found in event text (conference link detection and Join)
- Credentials and tokens for future calendar sources
- The release process and build scripts in this repository

## Supported versions
Only the latest release receives security fixes.

## Bounty
TimeTug is a volunteer project; there is no bug bounty.
